# Блог Ивана - Сайт-визитка

Простой и стильный сайт-визитка для блога о маркетинге, AI и личном опыте.

## 🚀 Особенности

- **Минималистичный дизайн** - тёмная тема, чистые линии
- **Полностью адаптивный** - отлично выглядит на всех устройствах
- **Быстрая загрузка** - без фреймворков, только чистый HTML/CSS/JS
- **SEO-оптимизирован** - семантическая разметка, мета-теги
- **Доступность** - следует принципам a11y

## 📁 Структура проекта

```
blog-portfolio/
├── index.html          # Главная страница
├── posts.html          # Страница статей
├── about.html          # Страница "Обо мне"
├── assets/
│   ├── css/
│   │   └── style.css   # Все стили
│   └── js/
│       └── main.js     # JavaScript функциональность
└── README.md           # Этот файл
```

## 🎨 Дизайн-система

### Цвета
- **Фон**: `#0f0f0f` (основной), `#1a1a1a` (вторичный)
- **Карточки**: `#262626`
- **Текст**: `#ffffff` (основной), `#a3a3a3` (вторичный)
- **Акцент**: `#3b82f6` (синий)
- **Успех**: `#10b981` (зелёный)

### Компоненты
- **Кнопки**: Три варианта (primary, secondary, accent)
- **Карточки**: Для статей и контента с hover-эффектами
- **Навигация**: Липкий хедер с активными состояниями
- **Формы**: Валидация и удобный UX

## 🛠 Как запустить

### Локальный сервер (рекомендуется)
```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен live-server)
npx live-server

# PHP (если установлен)
php -S localhost:8000
```

Затем откройте `http://localhost:8000` в браузере.

### Просто открыть файл
Можно открыть `index.html` прямо в браузере, но некоторые функции (например, AJAX) могут не работать.

## 📱 Адаптивность

Сайт автоматически подстраивается под размер экрана:
- **Десктоп** (1200px+): Полная версия с сеткой
- **Планшет** (768px-1199px): Адаптированная сетка
- **Мобильный** (до 767px): Одна колонка, увеличенные кнопки

## ⚡ JavaScript функции

- **Плавная прокрутка** - для якорных ссылок
- **Анимации появления** - элементы появляются при прокрутке
- **Кнопка "Наверх"** - появляется при прокрутке вниз
- **Уведомления** - для копирования ссылок
- **Валидация форм** - если будут добавлены

## 🔧 Настройка

### Смена цветов
Все цвета определены в CSS-переменных в начале файла `style.css`:
```css
:root {
    --bg-primary: #0f0f0f;
    --accent: #3b82f6;
    /* и другие */
}
```

### Добавление контента
1. **Статьи**: Редактируйте `posts.html`
2. **Информация**: Обновите `about.html`
3. **Контакты**: Измените ссылки в футере

### Добавление новых страниц
1. Создайте HTML-файл
2. Скопируйте структуру из существующих страниц
3. Обновите навигацию во всех файлах
