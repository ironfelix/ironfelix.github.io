Ключевой вывод о регуляторном разрыве

Kalshi — CFTC-регулируемая биржа, что даёт ей доступ к американской аудитории. Polymarket работает на USDC/Polygon и юридически недоступен для американцев. Это объясняет почти всю разницу в оценке. Для B2B-продуктов это значит: инфраструктура вокруг Polymarket ориентирована на международную аудиторию и крипто-трейдеров.

🎮 Гипотеза: киберспорт — незанятая ниша?

⚡
ЧАСТИЧНО ВЕРНО — ниша есть, но маленькая
Киберспорт на Polymarket существует и торгуется реально. Топовый рынок — IEM Cologne Major 2026 Winner — достиг $15M объёма. Однако большинство матчей торгуются на $49K–$333K, что крайне мало по сравнению с политическими/макро рынками (сотни миллионов). Ниша свободна в смысле «нет крупного игрока специфично под киберспорт», но и сам рынок тонкий.
Рынок / Турнир Объём Тип Оценка
IEM Cologne Major 2026 Winner $15M CS2 Топ
CS2 / LoL — матчи среднего уровня $189K – $333K Matchup Средний
Матчи нижнего эшелона $49K – $67K Matchup Тонкий
Политика (для сравнения) $100M – $500M+ Politics Доминирует

Что это значит для бизнеса

Ниша киберспорта на Polymarket ликвидна только вокруг крупных турниров (IEM Major, Worlds LoL и т.д.). Для создания аналитического продукта под киберспорт данных недостаточно. Зато это свободное окно для медийного/SEO-продукта: агрегатор предсказаний по киберспорту с образовательным контентом и трафиком из поиска. Аналог — спортивные prediction-сайты, но для esports. Самое интересное: Kalshi активно растёт в спорт-предсказаниях и туда можно идти напрямую как агрегатор или аналитик.

Продукт под SEO-трафик — конкретная идея

Esports Prediction Tracker — сайт-агрегатор предсказаний по киберспорту с Polymarket + Kalshi + другие платформы. SEO-блог с разбором турниров, «кто поставил сколько», исторические данные по точности. Монетизация: реферальный трафик на платформы (affiliate), платный email-дайджест для серьёзных беттеров. Конкурентов в этой точке пересечения почти нет — есть киберспортивные медиа и есть prediction-медиа, но нет пересечения.

🚀 Рейтинг возможностей

1
B2B Data API — кросс-платформенная аналитика
Falcon API и FinFeedAPI уже существуют, но рынок растёт быстрее, чем они успевают. Нишевые API для конкретных аудиторий (трейдеры, медиа, кванты) с лучшим UX — реальная возможность. Особенно интересно: арбитраж цен между Polymarket и Kalshi в реальном времени.
Сложность: высокая B2B $99–$999/мес ARR
2
Esports Prediction Media + SEO-актив
Медиа-продукт на пересечении киберспорта и prediction markets. Агрегирует рынки IEM, Worlds, ESL с аналитикой. SEO под запросы типа «prediction market esports». Монетизация через аффилиат. Гипотеза частично верна — ниша есть, конкурентов в этом пересечении нет.
Сложность: низкая SEO / медиа Affiliate + ads
3
Whale / Smart Money Tracker под Kalshi
Polywhaler существует для Polymarket ($9/мес). Для Kalshi аналога с хорошим UX нет. У Kalshi 89% рынка, огромный объём — трейдеры хотят видеть кто ставит на спорт, какие паттерны. Продукт: уведомления + дашборд для трейдеров Kalshi.
Сложность: средняя B2C $9–49/мес
4
Арбитражный бот Polymarket ↔ Kalshi
Одинаковые события торгуются на обеих платформах по разным ценам. Falcon API уже строит price disagreement detection. Бот, который автоматически находит и закрывает арбитражные окна — работающая модель. Или SaaS-инструмент для трейдеров с алертами.
Сложность: высокая Prop trading / SaaS P&L или $200+/мес
5
Newsletter / Дайджест для трейдеров
Еженедельный разбор крупных движений рынка: кто ставит на что, какие события дают аномальные шансы, recap. Audience: профессиональные трейдеры + любопытные. Beehiiv/Substack, монетизация — sponsors + платный tier.
Сложность: низкая Newsletter Sponsorships + paid tier

⚠️ Важные оговорки

Kalshi считает объём иначе (номинал $1/контракт), Polymarket — нотионал тейкера. Прямое сравнение завышает долю Kalshi.
Оценки движутся стремительно: Kalshi $5B (октябрь 2025) → $11B (декабрь) → $22B (май 2026) за 7 месяцев. Все цифры — снимок в моменте.
Esports $15M — это один рынок во время активного турнира. Типичный ежедневный объём на большинстве матчей значительно ниже.
Polymarket планирует запуск токена — это может изменить структуру ликвидности и сделать текущие аналитические инструменты менее актуальными.
Точная бизнес-модель Polymarket (размер комиссий, дата введения) остаётся неясной из верифицированных источников.
